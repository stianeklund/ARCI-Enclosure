# Engineering references

These files support measurement, fit checks, and historical reconstruction.
They are not production exports and are not required to print the enclosure.

- `legacy/` contains source geometry used to reconstruct the native enclosure.
- `waveshare/` contains independently modeled display reference geometry. See
  the repository [NOTICE](../../NOTICE.md) for provenance and trademark notes.

`cad/step/` contains the supported isolated-part neutral-CAD exports.
`cad/assembly/` contains separately exported, non-printable project-authored
inspection assemblies. Neither directory includes the historical references in
this folder.
